配置领英 Cookie (获取点赞者及主页)

最简单且防失效的步骤（10秒搞定）：
1. 电脑浏览器登录并打开 linkedin.com。
2. 按 F12 打开开发者工具，点击 Network (网络) 标签。
3. 刷新页面，在网络请求列表中点击任意请求（如 feed 或 voyager）。
4. 在右侧 Request Headers (请求标头) 中找到 Cookie:，右键点击 “复制值 (Copy value)”。
5. 直接粘贴到下方文本框中（程序会自动提取配套的 li_at 与 JSESSIONID，彻底杜绝 CSRF 校验失败）。
⚠️ 关键提醒：复制后请勿在网页点击“退出登录（Sign Out）”，否则领英会立即将该会话彻底注销！

为什么必须同时填写 JSESSIONID？

领英 Voyager API 强制校验 JSESSIONID 作为 CSRF Token。如果只填 li_at，领英会判定为跨站请求并主动返回 delete me 注销该 Cookie！

两个 Cookie 均可在 F12 → Application (应用程序) → Cookies → linkedin.com 中找到。
